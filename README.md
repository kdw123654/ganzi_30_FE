# ON-DO

직장인이 직무별 섬에서 익명으로 고민을 나누고, AI 이웃 "온도"와 같은 고민을 먼저 겪은 이웃에게 위로를 받는 서비스입니다.

- FE 배포 주소: (배포 후 추가)
- BE API 문서: https://ondo-api.onrender.com/docs

## 바로 체험하기

1. 첫 화면에서 **섬으로 떠나기**를 누릅니다.
2. **체험 계정으로 둘러보기**를 누르면 `demo@example.com`으로 바로 로그인됩니다.
   - 직접 입력해도 됩니다. 이메일에 `demo@example.com`을 넣고 인증코드를 받으면 화면에 체험용 코드가 표시됩니다.
3. 섬을 고르고 고민을 읽거나 써 보세요.

> 무료 서버라 첫 요청은 최대 50초 걸릴 수 있어요. 첫 화면을 열면 서버를 미리 깨웁니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 직무섬·통합섬 | 같은 직무끼리 모이는 섬과 모두가 모이는 섬 |
| 살아 있는 섬 | 방향키(WASD)로 내 캐릭터를 움직이고, 지금 접속한 이웃이 실시간으로 돌아다님. 고민을 쓰면 그 자리에 내 형체와 글 말풍선이 남음 |
| 공명 | 내 고민과 비슷한 고민을 쓴 이웃의 캐릭터가 내 곁으로 다가오고 머리 위에 🔥 공명 이펙트가 뜸 (임베딩 유사도) |
| 닮은 고민 말풍선 | 내용이 닮은 이웃 고민은 지도에서 말풍선 하나("+N")로 합쳐져 이웃이 많아져도 지도가 가벼움. 누르면 묶인 고민 목록 |
| 12간지 페르소나 | 캐릭터 성격에 따라 💗 긍정적 공감형 · 🧭 실전 경험 조언형 · 💡 현실 솔루션형 칭호가 댓글에 붙음 |
| 활동 칭호·칭호 도감 | 위로·첫 위로·고민 나누기 활동으로 칭호 13종(새싹·따뜻한·빛나는·전설)을 얻음. 댓글·피드·지도 이름표에 표시되고, 프로필 칭호 도감에서 진행도를 보고 대표 칭호를 고름 |
| ⚓ 섬지기 | 섬의 규칙·안전을 맡는 운영자 캐릭터. 요일·시간대마다 직장인이 겪는 순간을 짚는 한마디(110개, 예: 일요일 밤 출근 걱정). 지도 말풍선은 이 한마디와 이번 주의 질문을 번갈아 보여 줘요. 누르면 이번 주의 질문(바로 글쓰기), 최근 7일 섬 소식, 이용 원칙, 위기 상담 안내(기본은 접혀 있고 눌러서 펼침). 신고·가림·이의 제기 알림도 섬지기가 전함 |
| 📊 섬 고민 리포트 | 섬지기 창의 두 번째 탭. 매일 아침 8시에 새로 정리됨. 쌓인 공개 고민으로 많이 나눈 주제 순위와 이번 주에 늘어난 주제, 고민이 올라오는 요일·시간대, 바라는 위로, AI가 내용으로 묶은 "결이 닮은 고민", 내 고민과 공명하는 이웃 수, 직무섬별 비교를 보여 줘요. 오늘 공감이 모인 고민과 아직 답을 기다리는 고민을 한 개씩 나란히 둠 |
| ✍️ 조금 더 적어 볼래요? | 게시 전 점검에서 본문이 20자 미만이거나, 제목을 그대로 옮겼거나, "ㅠㅠ"·반복 글자가 절반 이상이면 막지 않고 더 적어 보라고 권해요 (규칙 기반, AI 미사용). |
| 12간지 보안관 | 회사명·연락처를 쓰면 보안관 호랑이가 가려서 보여 주고, 버튼 한 번으로 가린 내용으로 고쳐 줌 |
| 섬 온도·모닥불 | 고민과 위로 댓글이 쌓일수록 섬 중앙 모닥불이 커지고 날씨가 따뜻해짐 (목표 36.5°) |
| 유리병 편지 | 하루 한 통, 아침 8시에 강물로 떠내려옴. 열면 다른 섬의 고민과 글쓴이의 "그 뒤 이야기"가 들어 있고, 답장을 담아 다시 띄움. 읽고 나면 사라지고 다음 날 아침 8시에 새 편지가 옴 |
| 나만보기 AI 대화 | 나만보기 고민에서는 온도와 둘만 대화. 공개로 바꿔도 이 대화는 이웃에게 보이지 않음 |
| 살아 있는 섬 연출 | 시간대별 빛, 구름 그림자, 강물 반짝임, 모닥불 빛, 새·꽃잎·반딧불이, 캐릭터 숨쉬기 |
| 시간대 배경·색감 | 시간에 맞춰 일출·낮·노을·밤 배경이 바뀌고, 🎨 팔레트로 캐릭터 색감을 고름 |
| 이메일로 시작하기 | 가입·로그인 구분 없이 회사 이메일과 인증코드 하나로 시작 (비밀번호 없음). "로그인 유지"를 체크하면 30일 유지 |
| 실시간 알림 | 섬에 있는 동안 새 댓글·답글이 오면 배지와 알림이 바로 뜸 |
| 게시 전 AI 점검 | 올리기 전에 상처가 될 수 있는 표현을 찾아 형광펜으로 표시하고 고칠 방법을 안내 |
| AI 첫 댓글·이어 답글 | 이웃 댓글이 없는 글에 온도가 먼저 위로를 남기고, 글쓴이가 답하면 이어서 답글 |
| 비슷한 고민 연결·초대 | 글 상세에서 비슷한 고민을 먼저 겪은 이웃의 글을 보여 주고, 경험이 있는 이웃을 초대 |
| 답을 기다리는 고민 | 아직 이웃 댓글이 없는 글만 모아 보기 |
| 신고·이의 제기 | 신고가 쌓이면 가려지고, 작성자는 이의를 제기 |
| 위기 안내 | 위험 신호가 있는 글·댓글에 상담 전화(109, 1577-0199) 안내 |

## 실행

빌드나 패키지 설치가 필요 없는 바닐라 JS입니다. `index.html`을 브라우저로 열거나 VS Code Live Server로 실행하세요.

## 파일 구성

| 경로 | 역할 |
| --- | --- |
| `index.html`, `js/app.js` | 시작 화면, 회원가입·로그인(이메일 인증코드), 체험 계정 |
| `island-select.html`, `js/island-select.js` | 섬 선택 |
| `village.html`, `js/village.js` | 직무섬 화면과 설정 |
| `unified-island.html`, `js/unified-island.js` | 통합섬 화면과 설정 |
| `js/island/*.js` | 두 섬의 공통 동작 (기존 island-core.js를 기능별로 분리, HTML의 로드 순서 유지 필요) |
| `js/island/base.js` | 공통 유틸 · 상수 · 저장 상태 · 토스트 |
| `js/island/theme.js` | 시간대별 배경 테마 |
| `js/island/feed.js` | 고민 피드 목록 |
| `js/island/map.js` | 지도: 이웃 배치 · 마커 · 이름표/칭호 배지 · 검색 필터 · 처음 안내 |
| `js/island/live.js` | 공명 · 실시간 접속 · 섬 온도(모닥불) |
| `js/island/bottle.js` | 유리병 편지 |
| `js/island/keeper.js` | 섬지기 |
| `js/island/insights.js` | 섬 고민 리포트 · 닮은 고민 묶음 |
| `js/island/movement.js` | 방향키(WASD) 캐릭터 이동 |
| `js/island/comments.js` | 댓글 렌더링 · 신고 · 이의제기 |
| `js/island/post-detail.js` | 고민 상세 창 · 비슷한 고민 · AI 이어 답글 |
| `js/island/notifications.js` | 알림 배지 · 알림 목록 |
| `js/island/mypage.js` | 마이페이지: 내 글/댓글 · 차단 목록 · 프로필 · 칭호 도감 · 설정 · 탈퇴 |
| `js/island/editor.js` | 글쓰기 창 · 주제 선택 |
| `js/island/private-chat.js` | 나만보기 고민: 온도와 둘만의 대화 |
| `js/island/ambient.js` | 살아 있는 섬 연출 |
| `js/island/init.js` | 초기화 · 이벤트 연결 (반드시 마지막에 로드) |
| `js/api.js` | API 주소와 요청·에러 처리 |
| `js/review.js` | 게시 전 점검 브라우저 규칙 |
| `css/` | 화면별 스타일 (`island-extra.css`는 두 섬 공통) |
| `assets/` | 캐릭터, 직무 아이콘, 지도 배경 이미지 |

## 보안

- 모든 화면에 Content-Security-Policy를 적용해 외부 스크립트와 허용되지 않은 서버 연결을 막습니다.
- 서버에서 받은 글·댓글·닉네임은 화면에 넣기 전에 모두 이스케이프합니다.
